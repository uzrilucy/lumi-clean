# 루미 클린 v1.0.0

사진을 서버로 전송하지 않고 JPG/JPEG, PNG/APNG, WebP의 메타데이터를 지우는 설치형 웹앱입니다.

## 사용
사진을 선택하면 자동으로 정리합니다. 결과 사진을 개별 저장하거나 ZIP으로 저장하세요. 원본은 변경하지 않습니다. 파일당 50MB, 최대 50장, 합계 200MB까지 선택할 수 있습니다.

- 위치, 촬영일, 작성자, 기기 정보, EXIF/XMP/IPTC, 주석, 색상 프로필 제거
- 이미지 압축 데이터, PNG/WebP 투명도 및 애니메이션 유지
- 회전된 JPEG의 방향 보정 옵션: 활성화 시 해당 JPEG만 브라우저에서 품질 98%로 재인코딩합니다. 방향 보정은 최대 4,000만 화소까지 지원합니다.
- 사진 파일명 변경 옵션, 라이트/다크 화면, 홈 화면 설치, 오프라인 사용
- 외부 라이브러리·분석 도구·사진 업로드 API 없음. 화면 테마만 localStorage에 저장합니다.

색상 프로필 제거 시 색감이 달라질 수 있습니다. PNG/WebP의 EXIF 방향은 제거되므로 결과를 확인하세요. HEIC, GIF, SVG, RAW는 지원하지 않습니다. 사진에 보이는 얼굴·주소·워터마크·픽셀에 숨긴 정보는 제거하지 않습니다. 이미지 크기 등 표시 필수 정보와 JPEG Adobe 색상 해석 정보, 애니메이션 제어 정보는 남습니다. 일부 JPEG HDR 보조 이미지도 제거될 수 있습니다. OS의 파일 생성일 등은 다운로드 시 새로 지정될 수 있습니다.

## 설치와 호스팅
다운로드 ZIP은 모든 파일이 최상위에 있습니다. GitHub 저장소 최상위에 파일을 올린 뒤 Settings → Pages → Deploy from a branch → main → /(root)로 설정하세요. 별도 빌드가 필요 없습니다. GitHub Pages 기본 처리를 막기 위해 .nojekyll 파일을 포함했습니다.

HTTPS 주소를 안드로이드 Chrome에서 열고 메뉴 → 홈 화면에 추가 또는 앱 설치를 선택하세요. '오프라인 사용 준비 완료' 안내 후 인터넷 없이 다시 열 수 있습니다. 기기에서 캐시를 비우면 첫 접속에 인터넷이 필요합니다. APK는 포함되지 않으며 설치형 웹앱(PWA)입니다.

PC 로컬 확인: 압축을 푼 폴더에서 `python3 -m http.server 8080` 실행 후 `http://localhost:8080` 접속. index.html을 파일 앱에서 직접 여는 방식은 ES 모듈 및 서비스워커 제한으로 지원하지 않습니다.

## 검증
메타데이터가 있는 15개 JPEG(진행형 포함)·PNG·애니메이션 PNG·WebP·애니메이션 WebP를 정리한 뒤 독립적인 Pillow 디코딩으로 픽셀·프레임 수·메타데이터 제거를 검증했습니다. ZIP CRC/한글 이름 검사, 지원하지 않는 파일 3개 및 잘린 파일 9개 거부를 확인했습니다. 브라우저에서 파일 선택·방향 보정·결과 표시·오류 안내, 320px/390px 화면 및 다크 모드를 확인했습니다. 원격 브라우저의 다운로드 이벤트는 확인되지 않아 실제 기기 저장 완료 및 홈 화면 설치는 실기기 최종 확인이 필요합니다.

## 개발
배포 소스는 dist/에 있습니다. 브라우저용 app.mjs와 이미지 정리/ZIP 생성용 cleaner.mjs를 분리했습니다. 서비스워커 캐시 버전은 수정 시 갱신하세요. PNG CRC, JPEG 스캔 구조, WebP 컨테이너를 검사하고, 정리 후 재검사한 파일만 저장 가능 상태로 표시합니다.
